# Substitution-saturation test (Fig. S8)

Diagnostic for how much phylogenetic signal the A29L alignment retains at depth,
in the MPXV A29 / OPG154 orthologue study. Everything reported is recomputed from
the two input files; no constant is hard-coded.

The script computes the statistics and writes them as CSV. **The published figure
was drawn manually in Excel** from those outputs (`plot_saturation.xlsx`); the
script does not produce a figure. See "Drawing the figure" below.

---

## What it does

For every pair of taxa it computes

| quantity | definition |
|---|---|
| **patristic distance** | sum of branch lengths along the path between the two tips in the ML tree, as `d(a, MRCA) + d(b, MRCA)`. Units are substitutions per site, i.e. whatever the tree's branch lengths are in. Root placement does not change it. |
| **observed p-distance** | fraction of differing positions over the columns where **both** sequences carry a residue (pairwise gap deletion). The denominator therefore varies between pairs and is reported per pair as `n_compared_columns`. |

and then quantifies the shape of the relationship:

- **initial slope** — least-squares slope of p-distance on patristic distance over
  pairs below `--linear-max` (default 1.0 substitutions per site), the window
  where the relation is still close to linear.
- **saturated-region slope, mean and occupancy** — least-squares slope, mean
  p-distance, and fraction of all pairs at or above `--plateau-min` (default 2.0
  substitutions per site).
- **compositional ceiling** — `1 − Σ fᵢ²` over the amino-acid composition of the
  whole alignment: the p-distance expected between two sequences drawn
  independently from that composition. This is the value the curve would approach
  if divergence were fully saturated.
- **binned means** — mean p-distance within fixed patristic bins, bins with fewer
  than 10 pairs dropped.

The window edges matter and are deliberately exposed as arguments. The slope and
the occupancy both change substantially with the threshold (see the `alt_*` rows
in `saturation_stats.csv`), so **the threshold quoted in the text must be the
threshold fitted at**. For the A29L data: 76% of pairs lie at or above 2
substitutions per site but only 65% at or above 4; the slope is 0.347 below 1 but
0.291 below 2 and 0.149 below 4.

## Requirements

Python ≥ 3.9 and `numpy`. Nothing else — the Newick parser and the distance code
are in the script, and the figure is drawn outside it.

```
pip install numpy
```

---

## Running it

```
python saturation_analysis.py \
    --msa  A29L_msa_linsi.fasta \
    --tree A29L.treefile \
    --outdir saturation_out
```

| flag | default | meaning |
|---|---|---|
| `--linear-max` | `1.0` | upper edge of the initial-slope fitting window |
| `--plateau-min` | `2.0` | lower edge of the saturated-region window |
| `--bin-width` | `0.5` | width of the patristic bins used for the binned means |

Inputs are copied into this folder from
`../../1_orthologs_msa/output_phase7/A29L_msa_linsi.fasta` and
`../output_iqtree/A29L.treefile`.

## Drawing the figure

`plot_saturation.xlsx` builds Fig. S8 from `saturation_pairwise.csv`. The chart
has five series:

1. **All pairs** — `patristic` against `p_distance`, scatter with markers only;
   marker size 2–3, grey fill, no border, ~85% transparency, so the density of the
   1,770 comparisons is visible rather than a solid mass.
2. **Binned means** — from `saturation_binned.csv`, plotted at the mean patristic
   distance within each bin (not the bin midpoint), as line with markers.
3. **Initial fit** — two points, `(0, b₁)` and `(1.75, m₁·1.75 + b₁)`, line only,
   dotted. Drawn slightly past its 1.0 window for legibility; it must not be
   extended to 2.0, which would imply a fit that was never made.
4. **Saturated-region fit** — two points, `(2, m₂·2 + b₂)` and `(10, m₂·10 + b₂)`,
   line only, dashed.
5. **Compositional ceiling** — two points at y = 0.9322, dotted horizontal line.

Coefficients come from `saturation_stats.csv` (`initial_slope`,
`initial_intercept`, `plateau_slope`, `plateau_intercept`). Format in Times New
Roman, y-axis fixed 0 to 1, no chart title, no gridlines, no legend, with the two
fitted equations as text boxes.

Because the figure is not regenerated by the script, `plot_saturation.xlsx` is
part of the deposit: it carries the chart definitions and the bin formulas.

## Results on the A29L input (60 orthologues, 300 columns, 1,770 pairs)

These are the numbers in the published figure; a run on these inputs reproduces
them to the last digit.

| statistic | value |
|---|---|
| compositional ceiling | 0.9322 |
| initial slope, pairs below 1 substitution per site (n = 207) | 0.3470 |
| initial intercept | 0.0408 |
| mean p, pairs at or above 2 substitutions per site (n = 1,351) | 0.7034 |
| slope over that region | 0.0167 |
| occupancy of that region | 76.3% of pairs |
| largest patristic distance | 9.844 |
| largest observed p-distance | 0.807 |
| mean p-distance, all pairs | 0.614 |

**Reading.** Below about 1 substitution per site observed divergence tracks the
tree with slope 0.35 — far below 1, so even there most inferred substitutions are
already hidden by multiple hits. Beyond 2 substitutions per site the relationship
decelerates sharply (slope 0.017): across the remaining five-fold increase in
patristic distance the binned means rise only from 0.58 to 0.77, against a ceiling
of 0.93, and 76% of all taxon pairs lie in that region. The marker is therefore
heavily saturated across most of the tree: the deep internal splits are being
inferred from pairs that carry little residual signal, which is the mechanism
behind the weak backbone support and the inability of the AU tests to distinguish
constrained from unconstrained topologies.

**Note on the word "plateau".** At 0.5-unit bin width the region above 2
substitutions per site is not flat — the binned means climb steadily from 0.578
to 0.768 with no level stretch. It is a sharp deceleration, not a plateau, and a
single straight fit across it necessarily overshoots at the left edge. The
statistic names in `saturation_stats.csv` retain `plateau_*` for continuity with
earlier runs, but the text should describe deceleration rather than a plateau.

**What this does and does not show.** The x-axis comes from the same ML fit that
produced the tree, so it is a model-corrected distance, not an independent
measurement — the diagnostic tests internal consistency between the fitted branch
lengths and the raw data, not the correctness of the model. Levelling at 0.70
rather than 0.93 means divergence is heavily, not completely, saturated; some
signal remains, which is why genus-level clades are still recovered with support.
Pairwise gap deletion is the right choice here and not a neutral one: scoring all
300 columns instead — where a column gapped in both sequences counts as a match —
deflates everything (initial slope 0.124, region mean 0.400) and yields a curve
whose level is not comparable to any substitution model. The shape survives, but
the level is only interpretable under pairwise deletion.

## Notes for reuse on your own data

- **Tip labels must match FASTA headers exactly.** This is the usual failure
  mode, because tree inference programs rewrite characters they consider unsafe.
  The script refuses to run on a mismatch and prints the offending labels rather
  than silently dropping taxa. Rename both files to a common set of short safe
  identifiers (`S01`…`Sn`, letters, digits and underscore only) if you hit this.
- **The tree must carry branch lengths.** A consensus topology without lengths,
  or a cladogram, gives all-zero patristic distances. For IQ-TREE output use
  `.treefile` (ML branch lengths), not `.contree`, whose internal labels are
  support values.
- **The tree may be a subset of the alignment, but the script does not subset for
  you** — it requires the two label sets to be identical. Prune the tree and
  filter the FASTA to the same taxa first.
- **Defaults are tuned to a protein at this divergence.** For a slowly evolving
  marker the whole dataset may lie below 1 substitution per site, in which case
  `--plateau-min` has no pairs above it and those statistics come back as `nan`;
  raise `--linear-max` and lower `--plateau-min` to windows that match your own
  curve, and quote the windows you used.
- Runtime is dominated by the O(n²) pair loop: about 3 s for 60 sequences, a few
  minutes for ~500.
