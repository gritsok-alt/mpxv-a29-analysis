# Socket2 — knobs-into-holes analysis

Structure-based validation of the heptad register of the MPXV A29 restrained
model against the vaccinia A27 crystal structure.

**Date run:** 24 September 2026
**Operator:** D. Gritsok

---

## Purpose

The heptad register used throughout this work (*a* at 51, 58, 65, 72, 79, 86, 93;
*d* at 47, 54, 61, 68, 75, 82, 89, 96) was derived from sequence alone, using
four coiled-coil predictors, and was recorded before any three-dimensional model
existed. It was deliberately **not** supplied to the structure prediction: the
restraints imposed on the model constrain only residues 47 and 65 of two chains,
and no template was used.

Socket2 assigns the register from the coordinates, by locating knobs-into-holes
(KIH) packing. Agreement between the two therefore constitutes independent
validation rather than a restatement of an input.

## Input files

| File | Description |
| --- | --- |
| `A29_s2m0.pdb` | Reported MPXV A29 model: Boltz-2 v2.2.1, restraint set S1, seed 2, sample 0. Selected from 100 models by highest ipTM. |
| `xtal.pdb` | PDB 3VOP biological assembly (`3vop-assembly1.cif`), non-polymer removed, zero-occupancy placeholder residues removed, numbering offset by +20 to native A27 numbering. |
| `*.dssp` | Secondary structure assignments generated by mkdssp. |

**Chain convention.** Both PDB files were exported from PyMOL *after*
relabelling, so that in each structure **C is the antiparallel chain**, **A
presents the heptad *g* face to C**, and **B presents the *e* face**. Boltz
assigns chain identifiers arbitrarily, so the `partner` lines in the Socket
output cannot be interpreted without this. The relabelling was determined from
per-chain helix-axis dot products and Cβ–Cβ contacts at *e* and *g* positions,
not by sequence alignment, which cannot distinguish identical chains.

## Commands

```bash
# obtain Socket2
cd ~
curl -sLO https://raw.githubusercontent.com/woolfson-group/Socket2_colab/main/socket2_linux
chmod +x socket2_linux

# DSSP
sudo apt install -y dssp
mkdssp A29_s2m0.pdb A29_s2m0.dssp
mkdssp xtal.pdb     xtal.dssp

# Socket2, two packing cutoffs
~/socket2_linux -f A29_s2m0.pdb -s A29_s2m0.dssp -c 7.0 > socket_model_7.0.txt
~/socket2_linux -f A29_s2m0.pdb -s A29_s2m0.dssp -c 7.4 > socket_model_7.4.txt
~/socket2_linux -f xtal.pdb     -s xtal.dssp     -c 7.0 > socket_xtal_7.0.txt
~/socket2_linux -f xtal.pdb     -s xtal.dssp     -c 7.4 > socket_xtal_7.4.txt

# read the register blocks
for f in socket_*.txt; do
  echo "=== $f ==="
  grep -A6 "assigning heptad" "$f"
  tail -2 "$f"
done
```

`-c` sets the packing cutoff in ångströms: the distance within which a knob's
centre of mass must lie from all four side chains forming the hole. Smaller
values require more ideal packing. Two values were used because the models were
not energy-minimised, so genuine packing at the edges of the coiled coil may
fall marginally outside a strict cutoff.

Note: `mkdssp` 4.5.7 prints `parse error at line 1: This file does not seem to
be an mmCIF file` when given a PDB file, but writes a valid classic-format DSSP
file regardless. The message can be ignored; verify by checking that the output
contains a `#  RESIDUE AA STRUCTURE` header and one line per residue.

## Results

Both structures, both cutoffs: **COILED COILS PRESENT**, with **zero
non-canonical interrupts** in every chain.

### Register assignment (native A27/A29 numbering)

| Structure | Cutoff | Chain | Packed range | *a* positions | *d* positions | Repeat pattern |
| --- | --- | --- | --- | --- | --- | --- |
| Model | 7.0 | A | 47–68 | 51, 58, 65 | 47, 54, 61, 68 | 4,7,7,4 |
| Model | 7.0 | B | 47–68 | 51, 58, 65 | 47, 54, 61, 68 | 4,7,7,4 |
| Model | 7.0 | C | 44–65 | 44, 51, 58, 65 | 47, 54, 61 | 7,7,7,1 |
| Model | 7.4 | A | 44–79 | 44, 51, 58, 65, 72, 79 | 47, 54, 61, 68, 75 | 7,7,7,7,7,1 |
| Model | 7.4 | B | 44–78 | 44, 51, 58, 65, 72 | 47, 54, 61, 68, 75 | 7,7,7,7,7 |
| Model | 7.4 | C | 44–68 | 44, 51, 58, 65 | 47, 54, 61, 68 | 7,7,7,4 |
| Crystal | 7.0 / 7.4 | A | 48–65 | 51, 58, 65 | 54, 61 | 3,7,7,1 |
| Crystal | 7.0 / 7.4 | B | 47–65 | 51, 58, 65 | 47, 54, 61 | 4,7,7,1 |
| Crystal | 7.0 / 7.4 | C | 47–58 | 51, 58 | 47, 54 | 4,7,1 |

All nine assignments are mutually consistent and agree with the register
derived from sequence.

### Helical content and packing

| | Helical residues | 3-knob cycles |
| --- | --- | --- |
| Model | 207 | 5 |
| Crystal | 112 | 2 |

The model packs over a longer stretch because it covers the full 110-residue
protein, whereas 3VOP resolves only residues 45–84 (chains A, B) and 42–84
(chain C).

### Effect of the cutoff

The crystal is identical at 7.0 and 7.4 Å, indicating well-formed packing. In
the model the looser cutoff **extends** the packed region (chain A: 47–68 →
44–79) without reassigning any position, and the repeat becomes a perfect
7,7,7,7,7,1 over 36 residues. The register is therefore robust to the cutoff.

### Residues identified as knobs

Model: Leu47, Leu51, Leu54, Ile58, Ile61, Phe65, Ile68 (all *a* or *d*), plus
Arg50 and Lys64 at *g*.
Crystal: Leu47, Leu51, Leu54, Ile58, Val61, Phe65, Ile68, plus Arg50 at *g*.

No knob falls at a *b*, *c* or *f* position in either structure.

The model has **Ile61** where the crystal has **Val61** — the genuine V61I
substitution between VACV A27 and MPXV A29. It occupies the same *d* position
and forms equivalent knobs, so the substitution is accommodated without
perturbing the register.

### Topology

The `partner` lines record which helix each knob packs into. Chain A alternates
Z–Y–Z–Y–Z–Y in both the model and the crystal, so the arrangement of partners
around the bundle is reproduced, not only the register.

---

## Interpretation

Socket2 assigned an uninterrupted heptad register in both structures and at both
cutoffs, placing *a* at 51, 58 and 65 and *d* at 47, 54, 61 and 68 — matching the
register derived independently from sequence in Section 3.2 of the manuscript.
Since no register, template or secondary-structure information was supplied to
the prediction, and the two imposed restraints constrain only chain
directionality at residues 47 and 65, this agreement is independent evidence
that the restrained model reproduces the coiled-coil packing of the orthologous
crystal structure.
