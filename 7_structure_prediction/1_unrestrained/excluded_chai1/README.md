# Chai-1 — run but excluded from the benchmark

This folder documents predictions made with **Chai-1** on the Chai Discovery
web platform (https://lab.chaidiscovery.com/dashboard) and the reason they were
excluded from the unrestrained benchmark. The runs are kept here because a
documented exclusion is verifiable, whereas an unmentioned one is not.

## What was run

| | |
| --- | --- |
| Targets | full-length MPXV A29 and full-length VACV A27 |
| Stoichiometry | three identical chains (models contain 330 Cα, i.e. 3 × 110 residues) |
| Submissions | 5 per target (`Chai-A29-run-1…5`, `Chai-A27-run-1…5`) |
| MSA | generated by the service with MMseqs2 ("Use MSAs" enabled) |
| Templates | not used |
| Restraints | not used |
| Date | 11 September 2026 |

The platform exposes only these three options (MSA on/off with MMseqs2,
templates, restraints). **There is no seed and no sampling control**, so
repeated submission of the same input cannot produce independent samples.

Each submission returns five ranked models (`pred.rank_0.cif` …
`pred.rank_4.cif`), their predicted aligned error matrices (`pae.rank_*.npy`)
and confidence scores (`scores.rank_*.json`: `aggregate_score`, `ptm`, `iptm`,
`per_chain_ptm`, `per_chain_pair_iptm` and clash flags).

## Why the runs were excluded

The models were compared with `compare_chai1_coordinates.py` (Cα coordinates; maximum
deviation as written, and RMSD after optimal superposition). Full output is in
`chai1_comparison_a29.txt` and `chai1_comparison_a27.txt`.

**Across submissions** (top-ranked model of each), four of the five
submissions returned **byte-identical coordinates** (maximum deviation
0.000 Å) for both targets. One submission differed in each case (run 2:
Cα RMSD 11.6 Å for A29 and 4.0 Å for A27), for reasons outside the user's
control, as no parameter was changed between submissions.

**Within a submission**, the five ranked models differ substantially from one
another (Cα RMSD 5.9–26.0 Å for `Chai-A29-run-1`), so the model itself does
sample alternative arrangements.

Chai-1 was therefore excluded not because it produced a single structure, but
because repeated submissions are not independent: five submissions yield the
diversity of one, and no ensemble comparable to those from AlphaFold3
(AlphaFold Server), ColabFold v1.6.2 and Boltz-2 v2.2.1 can be obtained. No
Chai-1 result is reported in the article.

## Reproducing the comparison

From this folder:

```bash
python compare_chai1_coordinates.py Chai-A29-run-1 Chai-A29-run-2 Chai-A29-run-3 \
       Chai-A29-run-4 Chai-A29-run-5 --rank 0      # across submissions
python compare_chai1_coordinates.py Chai-A29-run-1                     # within one submission
```

`--rank 0` restricts the comparison to the top-ranked model of each
submission. The script requires numpy and biopython.
